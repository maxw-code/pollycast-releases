# Pollycast releases

Release files for Pollycast, a Windows broadcaster for Icecast. Pollycast reads this repository to update itself.

Each release holds:

- `Pollycast-v<version>-win-x64.zip`: the program
- `Pollycast-v<version>-win-x64.zip.sha256`: its SHA-256
- `pollycast-ffmpeg-source-<version>.tar`: the exact source of the FFmpeg it ships, under the GNU LGPL

Pollycast itself is private, with all rights reserved. These files are public so that Pollycast can download them, and no licence to use, copy or share Pollycast is granted. That needs the owner's written permission.

FFmpeg and the other open-source parts stay under their own licences, listed in `app\THIRD-PARTY-NOTICES.txt` in each ZIP.
